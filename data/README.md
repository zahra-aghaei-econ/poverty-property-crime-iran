# Data

The data are not included here. Put them in this folder with these names:

| Path | What it is | Source |
|---|---|---|
| `hies/SumR90.xlsx` ... `hies/SumR99.xlsx` | HIES summary files, rural households, 1390-1399 | Statistical Centre of Iran |
| `hies/SumU90.xlsx` ... `hies/SumU99.xlsx` | HIES summary files, urban households, 1390-1399 | Statistical Centre of Iran |
| `crime_1390_1400.xlsx` | Registered theft cases by province and type, typed in from the statistical yearbooks (column `شرح2` = province, `Year`) | SCI statistical yearbooks, judicial section |

The HIES microdata are free to download from the SCI website after registration.
